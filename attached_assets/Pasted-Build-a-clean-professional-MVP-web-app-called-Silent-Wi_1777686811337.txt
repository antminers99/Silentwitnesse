Build a clean, professional MVP web app called “Silent Witness”.

Purpose:
Silent Witness is a privacy-first evidence fingerprinting tool. It lets a user create a cryptographic fingerprint for a photo, video, audio file, document, or written testimony without uploading the original evidence. The user may optionally publish only the fingerprint and safe public metadata. The app must never claim that an event is proven. It only proves that a matching file/text existed before a certain timestamp if the original is later provided.

Important tone:
- No hype.
- No AI branding.
- No dramatic visuals.
- No fake claims.
- Simple, trustworthy, human-rights-documentation style.
- Minimal, elegant, mobile-first design.
- English UI only.
- Make it look credible, not flashy.

Tech stack:
Use React + Vite + TypeScript.
Use a small Express backend with SQLite only for public records.
Use Tailwind CSS or clean CSS.
Use Web Crypto API in the browser for SHA-256 hashing.
Use a client-side EXIF library such as ExifReader or exifr to detect metadata/GPS locally.
Do not upload evidence files to the server.
The server stores only public records submitted by the user: hashes and safe metadata.

Core rule:
Files must be processed locally in the browser. Original images, videos, audio, and documents must never be sent to the backend.

3. Create Witness Record page /create
This is the main tool.

Layout:
A simple 3-step flow.

Step 1: Choose record type
Buttons:
- File evidence
- Written testimony
- Evidence package

File evidence:
User selects one or multiple files.
Calculate SHA-256 for each file locally.
For images:
- Read EXIF locally.
- Detect whether GPS metadata exists.
- Detect whether camera/device metadata exists.
- Do not display exact GPS coordinates.
- Display only:
  GPS metadata: present / absent / unknown
  EXIF metadata: present / absent / stripped / unknown
  Image dimensions
  File size bucket: small / medium / large
For videos:
- Use browser video metadata if possible.
- Display duration bucket:
  0–5s, 5–15s, 15–60s, 1–5min, >5min
- Display resolution if available.
- Display file size bucket.
For text testimony:
- User writes text in a textarea.
- Calculate SHA-256 of the exact text.
- Count words.
- Detect language roughly: Arabic / English / mixed / unknown.
- Warn if the text contains phone numbers, GPS-like coordinates, or too many named entities.
No AI is needed. Use simple regex warnings.

Step 2: Safe public context
Fields:
- Event type: kidnapping, killing, detention, threat, theft, assault, displacement, other, withheld
- Evidence type: video, image, audio, document, written testimony, package, withheld
- Country: optional but encouraged
- Region / province: optional
- City: optional
- Public note: optional

Safety rules:
- Do not allow street address field.
- Do not allow GPS field.
- Do not ask for victim name, witness name, suspect name, phone number, or exact location.
- If the public note includes phone numbers, exact coordinates, very long personal names, vehicle plates, or phrases like “go kill”, show a red warning and do not allow public submission until the user edits it or marks it private.
- Let the user keep unsafe notes private in the downloaded proof package, but never submit them publicly.

Step 3: Generate record
Create a manifest JSON object like:

{
  "protocol": "silent-witness-v0.1",
  "recordType": "file_hash | testimony_hash | package_hash",
  "eventType": "...",
  "evidenceType": "...",
  "privacy": "details_withheld",
  "location": {
    "country": "...",
    "region": "...",
    "city": "..."
  },
  "safeDescriptor": {
    "mediaType": "...",
    "durationBucket": "...",
    "resolutionBucket": "...",
    "fileSizeBucket": "...",
    "wordCount": "...",
    "language": "...",
    "gpsMetadata": "present | absent | unknown",
    "exifMetadata": "present | absent | unknown"
  },
  "fileHashes": [
    {
      "nameHash": "sha256 of filename only, do not publish raw filename",
      "mimeType": "...",
      "sizeBytes": 123,
      "sha256": "..."
    }
  ],
  "packageHash": "sha256 of canonical JSON manifest without signature",
  "createdAtUtc": "...",
  "status": "timestamped_only_not_verified",
  "publicWarning": "Original evidence is not shared. This record does not prove guilt or truth."
}

Do not include raw filenames in the public record.
Show:
- Main fingerprint / package hash
- Individual file hashes
- Privacy warnings
- Verification instructions

6. About / Safety page /safety
Simple safety guide:
- Do not upload evidence to unknown servers.
- Keep originals safe.
- A fingerprint cannot recover a deleted file.
- If you delete the original and have no encrypted backup, the fingerprint alone cannot show the content.
- Public notes must not include names, exact places, or accusations.
- Use broader locations only.
- If publishing may put someone at risk, save locally only.

Backend:
Use Express + SQLite.
