Critical fixes:

1. Public record detail privacy:
GET /api/records/:packageHash must not expose pending_review, rejected_for_public_registry, or retracted_by_holder metadata publicly.
If publicationStatus is not public_timestamped_record or exact_match_published, return 404 or:
{ status: "not_public" }
Do not return eventType, location, safeDescriptor, createdAtLocal, or originalHash for non-public records.
Admin routes can still access all records.

2. Implement real Quality D:
Update computeQualityLevel so it can return D.
Return D when:
- safeDescriptor is empty or missing
- eventType = withheld and evidenceType = withheld and no meaningful descriptor
- testimony is too short or empty
- record is low value / unsafe / spam
Reject Quality D in POST /api/records with:
"Low-quality records can be saved locally but are not accepted into the public registry."

3. Make status server-only:
In POST /api/records, ignore body.status completely.
Always set:
status = "timestamped_only_not_verified"
publicationStatus = "pending_review"

4. Fix public copy on Create page:
Separate:
- Download Proof Package: full private manifest, includes retractionToken and private fields.
- Copy Public Record: safe public summary only.
The safe public summary must NOT include:
fileHashes, exact sizeBytes, raw or hashed filename, privateNote, retractionToken, full manifest internals.
It should include only:
packageHash, eventType, evidenceType, country/region/city, safeDescriptor, createdAtLocal, publicWarning.

5. Fix EXIF/GPS detection:
Do not store uncertain fields.
For images:
- Only set gpsMetadataDetected = "yes" if GPS tags are clearly detected.
- Do not set gpsMetadataDetected = "no" unless detection is confidently completed.
- Only set exifMetadataDetected = "yes" if actual EXIF fields are present.
- Otherwise omit these fields entirely.

6. Use resolution buckets, not exact dimensions:
Replace "1920x1080" style values with:
low / medium / high
Optionally derive from pixel count:
low < 1MP
medium 1MP–8MP
high > 8MP

7. Remove exact size from public descriptors:
Public descriptor should use only fileSizeBucket.
Exact sizeBytes may remain in the private proof package, but not in public records or copy-public output.

8. Restrict CORS for production:
Use an allowlist from env:
PUBLIC_APP_ORIGIN=https://silentwi.com
Allow localhost in development only.

9. README update:
Add a release-blocking checklist:
- pending records not exposed publicly
- Quality D rejected
- public copy is sanitized
- EXIF uncertain fields omitted
- status is server-only
- no original files uploaded
- body limit 100kb
- no Telegram
- no blockchain claims

Keep UI minimal and serious.
Do not add new features.
Only fix safety and correctness.
